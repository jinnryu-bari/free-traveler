## 자동 테스트 조사 결과 (참고용 — 1회성 조사, 재수행하지 않음)

Gallery의 실패-대체 동작을 자동 검증하려던 중, 이 세션에서 새로 만든 Client Component가 Playwright 테스트 브라우저에서 클릭·에러 이벤트를 전혀 받지 못하는 현상을 발견해 원인을 조사했습니다. 확인된 원인은 **Next.js 16의 `allowedDevOrigins` 교차 출처 차단** — Playwright 접속 주소(`127.0.0.1`)가 dev 서버 시작 origin(`localhost`)과 달라 dev 모드 리소스 요청이 차단되고 있었습니다. `playwright.config.ts`의 기본 `baseURL`을 `localhost`로 바꾸자 즉시 정상화됐고, 그 상태로 임시 테스트(일부러 사진 2장을 차단)를 돌려 대체 안내 표시와 레이아웃 유지를 확인했습니다. 다만 그 임시 테스트 코드는 이번 조사용으로만 쓰고 지웠고, 정식 테스트 스위트에는 포함하지 않았습니다(수업 실습 프로젝트 성격상 이런 edge-case 전용 자동 테스트를 상시 유지하는 것은 과도한 정교화로 판단 — `CLAUDE.md` 규칙 24 참고).

이 조사로 "왜 새 Component만 이 문제를 겪고 이전부터 있던 Component는 겪지 않았는지"는 규명하지 못했습니다 — 더 파고들지 않고 여기서 멈췄습니다.

## 남은 제약 / 수동 확인 필요

- **Gallery 이미지 로딩 실패 시 동작은 정식 자동 회귀 테스트로 확인되지 않은 상태입니다.** 코드는 작성·커밋되었고 1회성 수동 조사에서는 의도대로 동작했지만, 반복 가능한 형태로 검증되지는 않았습니다. 필요하시면 브라우저 개발자 도구 Network 탭에서 사진 요청 하나를 차단해 직접 확인해 주세요.
